# Roadmap

## v0.1 — validation environments

- `tg env list`
- `tg env status <env>`
- `tg env start <env>`
- `tg env stop <env>`

## Later, only after the MVP is useful

- Cross-account role assumption and clearer account identity
- Confirmation and dry-run options
- Tags or discovery as alternatives to explicit resource IDs
- Additional resource types
- Project scaffolding commands

AI, dashboards, event buses, and Project Purr integration are intentionally out
of scope for this version.
