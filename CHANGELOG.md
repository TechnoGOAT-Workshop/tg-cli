# Changelog

All notable changes to this project will be documented in this file.

The project follows a "small, incremental changes" philosophy.

---

## 0.1.0 - 2026-08-17

### Added

- Initial project structure
- Python packaging
- CLI framework
- Core domain model
  - Environment
  - Resource
  - ResourceType
- YAML configuration loader
- Unit test framework
- Project documentation

### Architecture

- Established provider-agnostic engineering domain
- Separated domain model from provider implementations
- Introduced configuration-driven environment definition

### Notes

This release establishes the project foundation.

No cloud provider functionality has been implemented yet.
